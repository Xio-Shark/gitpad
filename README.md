# GitPad

一个运行在 macOS 上的本地文件编辑与 Git 工具。左边是文件树，中间是编辑区，右边是 Git 面板，看文件、改内容、提交代码在一个窗口里完成。

## 安装

从 GitHub Releases 页面下载最新的 `.dmg` 安装包，拖到应用程序文件夹即可。

## 快速上手

1. 打开 GitPad，点击欢迎页的"打开文件夹"，选择一个文件夹作为工作区
2. 左侧出现文件树，点击文件在中间编辑区打开
3. 编辑、保存（`Cmd+S`），用右侧 Git 面板提交

## 文件浏览

### 文件树

- **点击目录**：展开/折叠
- **点击文件**：在编辑区打开
- **右键**：弹出菜单
  - 新建文件 / 新建文件夹（在目录下创建，新建文件会自动打开）
  - 重命名
  - 复制路径
  - 删除（删除目录会询问并提示会连同里面的内容一起删）
- **复制路径**：先点击一个文件或目录选中它（高亮），按 `Option+Cmd+C` 复制它的绝对路径到剪贴板；什么都没选时复制工作区根目录路径
- **工具栏按钮**：
  - `.` 显示/隐藏隐藏文件（`.gitignore` 规则仍然生效）
  - `nm` 显示/隐藏 `node_modules`
  - `↻` 手动刷新

### 快速打开

按 `Cmd+P`（或 `Ctrl+P`）弹出搜索框：

- 输入文件名，按名称或路径过滤
- `↑`/`↓` 选择，`Enter` 打开，`Esc` 关闭
- 文件过多（超过 2 万个）时会有提示，改用文件树浏览

## 编辑与查看

### 标签页

- 打开的文件以标签页显示在编辑区顶部，点击切换
- 点击标签上的 `×` 或**中键**点击标签关闭
- 有未保存修改时标签显示圆点，关闭前会询问

### 文本编辑

- 直接编辑，`Cmd+S` 保存
- 撤销等编辑操作与系统习惯一致（`Cmd+Z` 等）
- **代码折叠**：行号左侧的折叠槽点击即可折叠/展开代码块（`Ctrl+[` / `Ctrl+]` 等快捷键）
- **状态栏**：编辑区底部显示当前行/列、字符数和文件编码（UTF-8 / GBK）
- 文件过大（超过 10MB）时提示，不强行打开
- **编码**：支持 UTF-8 和 GBK/GB18030（常见中文本地文件），保存时按原编码写回，不会改变文件的编码

### 会话恢复

- 关闭应用后重新打开，会恢复上次工作区的标签页和当前选中标签（`git diff` 预览标签不恢复）

### Markdown 预览

- 打开 `.md` 文件默认是纯编辑模式
- 点击编辑区**右上角的 👁 眼睛按钮**切换到预览，再点一下回到编辑
- 预览支持标题、列表、表格、代码块等常见语法，以及 mermaid 图表（用代码块标注 `mermaid`）

### 图片 / PDF / CSV

- **图片**：直接显示
- **PDF**：工具栏支持缩放（`−`/`+`）、适应宽度、翻页（`◀`/`▶`）、搜索关键词（`↑`/`↓` 跳到上一个/下一个匹配）
- **CSV**：以表格形式显示，方便看数据

## Git

Git 面板在右侧，顶部显示当前分支和与远端相差的提交数（`↑2 ↓1` 表示领先 2 个、落后 1 个提交）。

### 查看变更

面板分三组列出变更文件：

- **已暂存**：已经进入暂存区、等待提交的修改
- **未暂存**：改了但还没暂存的修改
- **未跟踪**：新文件，还没加入 Git

点击任意变更文件，diff 会显示在**中间编辑区**，有足够的空间查看改动前后的每一行。

### 暂存与提交

- diff 里每个改动区块（hunk）前有复选框，勾选后点工具栏的**暂存**，可以只暂存一部分改动
- 已暂存的文件可以点**撤销暂存**，把改动退回未暂存状态
- 未跟踪的新文件点击后直接在编辑区打开内容，在面板里填提交信息后提交即可
- 提交：在面板底部输入框填写提交信息，点**提交**按钮，或按 `Cmd+Enter`
- 提交信息会实时显示字符数

### 拉取与推送

- 工具条右侧 `⇣` 拉取远端更新，`⇡` 推送本地提交
- 推送/拉取使用系统钥匙串里的凭据，支持 SSH 密钥认证
- 远端有别人推的新提交（推送会被拒绝）时，先 `⇣` 拉取合并，再推送
- 提交人信息取自仓库的 git 配置（`user.name` / `user.email`），没配置时提交会失败并提示

### 历史

点击面板顶部的**历史**标签：

- 展示提交列表和分支连线图（合并提交是菱形，当前所在分支用金色标记）
- 时间显示为"今天/昨天 + 时刻"或日期
- 点击任意提交，它改了什么会在中间编辑区显示

## 快捷键

| 快捷键 | 作用 |
| --- | --- |
| `Cmd+S` | 保存当前文件 |
| `Cmd+P` | 快速打开文件 |
| `Option+Cmd+C` | 复制选中的文件/目录路径 |
| `Cmd+Enter` | 在 Git 面板提交 |
| `Enter` | 快速打开列表中选中项 / 文件树中选中项 |
| `Esc` | 关闭搜索框、输入框、右键菜单等浮层 |
| 鼠标中键点击标签 | 关闭标签页 |

## 从源码运行

需要先装好 Node.js（20+）和 Rust 工具链。

```bash
npm install
npm run tauri dev
```

打包成安装包：

```bash
npm run tauri build
```

## 技术构成

- 桌面外壳：Tauri 2（Rust）
- 界面：Svelte 5
- Git 操作：git2（Rust 库，不依赖系统 git 命令）
- 字体：Maple Mono 等宽字体，用于代码和 diff 展示
