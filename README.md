# GitPad

一个运行在 macOS 上的本地文件编辑与 Git 工具。界面分成左右两栏：左边是文件树，右边是编辑区，再加上一个 Git 面板，日常看文件、改内容、提交代码都能在一个窗口里完成。

## 功能

### 文件浏览与编辑
- 打开本地文件夹作为工作区，目录树逐层展开
- 点击文件在中间编辑区打开，多个文件以标签页切换
- 文本文件直接编辑，支持撤销和保存（`Cmd+S`）
- 未保存的修改有圆点标记，关闭前会询问
- Markdown 文件可以切换预览
- 图片、PDF、CSV（表格形式）直接查看

### Git
- 变更列表分三组显示：已暂存、未暂存、未跟踪
- 点击变更文件，在中间编辑区查看改动前后的差异（diff），按区块勾选后可以只暂存一部分
- 填写提交信息即可提交（`Cmd+Enter`），支持撤销暂存
- 一键拉取（`⇣`）与推送（`⇡`），显示当前分支以及和远端相差的提交数
- 历史页面展示提交列表和分支连线图，点开提交可以看到它改了什么

## 安装

从 GitHub Releases 页面下载最新的 `.dmg` 安装包，拖到应用程序文件夹即可。

## 从源码运行

需要先装好 Node.js（20+）和 Rust 工具链。

```bash
npm install
npm run tauri dev
```

打包成安装包：

```bash
npm run tauri build
```

## 技术构成

- 桌面外壳：Tauri 2（Rust）
- 界面：Svelte 5
- Git 操作：git2（Rust 库，不依赖系统 git 命令）
- 字体：Maple Mono 等宽字体，用于代码和 diff 展示

## 说明

- Git 的推送和拉取会使用系统钥匙串里的凭据，支持 SSH 密钥认证
- 提交人信息取自仓库的 git 配置（user.name / user.email），未设置时提交会失败并给出提示
